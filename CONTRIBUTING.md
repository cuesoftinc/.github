# Contributing

This repository holds the Cuesoft organization profile (`profile/README.md`) and the default community health files that GitHub applies to repositories in the organization that do not carry their own.

## Getting started

1. Fork the repository, or clone it if you are a member of the organization.
2. Create a focused branch from `main`, named `<feature|bugfix>/<short-description>`.
3. Make the change. The repository is Markdown and YAML only: there is nothing to install, build or run.
4. Open a pull request against `main`.

## Before opening a pull request

- Check that Markdown tables render and links resolve in the GitHub preview.
- Use Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`), keep each commit to one line and keep changes focused.
- Never commit credentials, personal data or `.env` files.

## Code review

At least one approving review from a maintainer is required before merge. Be responsive to review feedback.

Participation is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
