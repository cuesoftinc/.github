# Security Policy

## Supported Versions

This repository holds documentation and community health files only. Fixes are applied to `main`.

## Reporting a Vulnerability

Do not use the regular issue tracker. Report vulnerabilities through the repository's **Security > Report a vulnerability** flow. If that option is unavailable, email `security@cuesoft.io` with the subject `Security vulnerability: .github`.

Include the impact, the affected file or component, reproduction steps and any suggested mitigation. Do not include credentials or confidential material. We aim to acknowledge reports within three business days.

## Secret and Data Handling

- Never commit `.env` files, keys or confidential material.
- Rotate a credential immediately if exposure is suspected.
